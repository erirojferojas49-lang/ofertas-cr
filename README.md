# 🛒 Ofertas CR - Comparador de Precios en Costa Rica

Sistema automatizado para comparar precios y detectar ofertas en tiendas de Costa Rica.

## ✨ Características
- Scraping de precios en tiempo real
- Detección automática de ofertas
- Dashboard interactivo con Streamlit
- Historial de precios por producto

## 🏪 Tiendas Soportadas
- Ekono
- Aliss
- Gollo
- EPA
- Novex
- Siman

## 🛠️ Tecnologías
- Python 3.10+
- PostgreSQL (Supabase)
- Streamlit
- BeautifulSoup4
